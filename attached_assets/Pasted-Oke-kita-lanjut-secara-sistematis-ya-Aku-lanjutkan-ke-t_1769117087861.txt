# 🔗 LANJUTAN: Integrasi E-Course Builder

## Mapping Kompetensi SMAP & PANCEK ke Level & Jalur Pengembangan

---

## 1️⃣ Arsitektur Ekosistem (Big Picture)

```
Strategic Objective Organisasi
        ↓
Ekosistem Kompetensi
        ↓
Klaster Kompetensi (SMAP | PANCEK)
        ↓
Unit Kompetensi
        ↓
E-Course (Learning Experience)
        ↓
Asesmen & Evidensi
        ↓
Talent Profile & Career Path
```

---

## 2️⃣ Level Kompetensi (Generic Framework)

Gunakan **4 level kompetensi** agar fleksibel lintas jabatan:

| Level            | Fokus          | Karakter                         |
| ---------------- | -------------- | -------------------------------- |
| L1 – Awareness   | Memahami       | Tahu konsep                      |
| L2 – Application | Menerapkan     | Bisa praktik                     |
| L3 – Mastery     | Mengoptimalkan | Konsisten & mandiri              |
| L4 – Strategic   | Mengarahkan    | Membimbing & mengambil keputusan |

---

## 3️⃣ Mapping SMAP ke Level Jabatan

### 🔹 Klaster SMAP (Strategic & Analytical)

| Unit Kompetensi          | L1                   | L2                 | L3                | L4                   |
| ------------------------ | -------------------- | ------------------ | ----------------- | -------------------- |
| SMAP-01 Analisis Masalah | Identifikasi masalah | Analisis sebab     | Sintesis strategi | Menentukan arah      |
| SMAP-02 Opsi Strategi    | Memahami opsi        | Membuat alternatif | Menilai risiko    | Menetapkan strategi  |
| SMAP-03 Data Decision    | Membaca data         | Gunakan data       | Insight strategis | Governance keputusan |
| SMAP-04 Monev            | Pahami indikator     | Monitoring         | Evaluasi dampak   | Re-design strategi   |

**Target Jabatan (contoh):**

* L1–L2 → Staf / Analis
* L3 → Supervisor / Manager
* L4 → Senior Manager / Leader

---

## 4️⃣ Mapping PANCEK ke Level Jabatan

### 🔹 Klaster PANCEK (Execution & Collaboration)

| Unit Kompetensi   | L1                | L2              | L3                  | L4                 |
| ----------------- | ----------------- | --------------- | ------------------- | ------------------ |
| PAN-01 Planning   | Ikuti rencana     | Susun rencana   | Optimasi rencana    | Sinkronisasi tim   |
| PAN-02 Komunikasi | Menyampaikan info | Negosiasi dasar | Pengaruh efektif    | Stakeholder mgmt   |
| PAN-03 Eksekusi   | Jalankan tugas    | Problem solving | Delivery excellence | Decision in crisis |
| PAN-04 Kolaborasi | Kerja tim         | Koordinasi      | Bangun sinergi      | Budaya kinerja     |

---

## 5️⃣ E-Course Builder per Level (Adaptive)

### Contoh: **SMAP-01 – Analisis Masalah**

| Level | Bentuk E-Course               |
| ----- | ----------------------------- |
| L1    | Video + kuis pemahaman        |
| L2    | Studi kasus + worksheet       |
| L3    | Project nyata unit kerja      |
| L4    | Strategic case & panel review |

➡️ **Satu unit kompetensi → 4 varian e-course**

---

## 6️⃣ Desain Asesmen Berbasis Kompetensi

### 🎯 Prinsip Asesmen

* Evidence-based
* Contextual
* Progressive (naik level = naik kompleksitas)

### Contoh Rubrik SMAP-01 (ringkas)

| Indikator            | L2          | L3           | L4             |
| -------------------- | ----------- | ------------ | -------------- |
| Identifikasi Masalah | Tepat       | Komprehensif | Strategis      |
| Analisis Akar        | Satu metode | Multi-metode | Sistemik       |
| Rekomendasi          | Layak       | Teruji       | Berdampak luas |
