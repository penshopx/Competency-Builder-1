# 🧩 E-Course Builder Berbasis Ekosistem Kompetensi

**Contoh Implementasi: Kompetensi SMAP & PANCEK**

## 1️⃣ Prinsip Dasar E-Course Builder

E-course **dibangun dari kompetensi**, bukan dari materi.

Alur logikanya:

```
Ekosistem Kompetensi
→ Klaster Kompetensi
→ Unit Kompetensi
→ Indikator Perilaku
→ Aktivitas Belajar
→ Asesmen & Evidensi
→ Sertifikasi / Recognition
```

---

## 2️⃣ Struktur Umum E-Course Builder

### A. Metadata Kompetensi

Setiap e-course **wajib diturunkan dari kompetensi**.

| Elemen             | Deskripsi                           |
| ------------------ | ----------------------------------- |
| Klaster Kompetensi | SMAP / PANCEK                       |
| Unit Kompetensi    | Spesifik & terukur                  |
| Level              | Dasar / Menengah / Lanjutan         |
| Outcome Kompetensi | Apa yang bisa dilakukan peserta     |
| Peran Target       | (contoh: Leader, Analis, Eksekutor) |

---

## 3️⃣ Contoh Kompetensi: SMAP & PANCEK

### 🔹 A. SMAP (contoh: Strategic Management & Analytical Planning)

**Tujuan Klaster**
Mengembangkan kemampuan berpikir strategis, analisis, dan pengambilan keputusan berbasis data.

#### Unit Kompetensi SMAP

| Kode    | Unit Kompetensi                     |
| ------- | ----------------------------------- |
| SMAP-01 | Analisis Masalah Strategis          |
| SMAP-02 | Perumusan Opsi Strategi             |
| SMAP-03 | Pengambilan Keputusan Berbasis Data |
| SMAP-04 | Monitoring & Evaluasi Strategi      |

---

### 🔹 B. PANCEK (contoh: Planning, Action, Negotiation, Communication, Execution)

**Tujuan Klaster**
Membangun kompetensi eksekusi, komunikasi, dan kolaborasi kerja.

#### Unit Kompetensi PANCEK

| Kode   | Unit Kompetensi            |
| ------ | -------------------------- |
| PAN-01 | Perencanaan Kerja Efektif  |
| PAN-02 | Komunikasi & Negosiasi     |
| PAN-03 | Eksekusi & Problem Solving |
| PAN-04 | Kolaborasi & Akuntabilitas |

---

## 4️⃣ Template E-Course Builder (Reusable)

### 📦 Struktur Modul E-Course

Setiap **1 Unit Kompetensi = 1 E-Course**

```
E-Course
 ├── 1. Orientasi Kompetensi
 ├── 2. Konteks Dunia Nyata
 ├── 3. Micro Learning
 ├── 4. Aktivitas Praktik
 ├── 5. Asesmen Kompetensi
 └── 6. Evidensi & Refleksi
```

---

## 5️⃣ Contoh E-Course: SMAP-01

### *Analisis Masalah Strategis*

### 1. Orientasi Kompetensi

* Deskripsi unit kompetensi
* Standar kinerja
* Indikator perilaku:

  * Mengidentifikasi akar masalah
  * Memilah masalah strategis vs operasional

---

### 2. Konteks Dunia Nyata

**Case Brief**

> “Organisasi mengalami penurunan kinerja meski target tercapai. Apa masalah strategisnya?”

Format:

* Video studi kasus
* Artikel singkat
* Infografik masalah

---

### 3. Micro Learning

Materi **ringkas & modular**:

* Tools analisis (SWOT, Fishbone, 5 Why)
* Framework berpikir strategis
* Kesalahan umum dalam analisis

⏱️ Durasi: 5–10 menit per micro unit

---

### 4. Aktivitas Praktik (Practice-Based)

* Analisis kasus nyata (individu / kelompok)
* Template worksheet
* Diskusi berbasis skenario

---

### 5. Asesmen Kompetensi

Bukan ujian hafalan ❌
Tapi:

* Project mini
* Analisis kasus tertulis
* Presentasi solusi

Rubrik berbasis **indikator kompetensi**

---

### 6. Evidensi & Refleksi

Peserta mengunggah:

* Dokumen analisis
* Video penjelasan
* Refleksi pembelajaran

➡️ Menjadi **portofolio kompetensi**

---

## 6️⃣ Contoh E-Course: PANCEK-02

### *Komunikasi & Negosiasi Efektif*

**Aktivitas Unggulan**

* Simulasi negosiasi (role play)
* Analisis komunikasi gagal
* Peer feedback

**Evidensi**

* Video simulasi
* Catatan refleksi
* Feedback rekan
